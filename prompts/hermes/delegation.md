# Hermes Agent / OpenClaw 跨调专用 Prompt

> Hermes ↔ OpenClaw / Claude Code / Codex / 任何子 agent 调度时用。

---

## 委派任务模板

当你希望另一个 agent 帮你完成子任务时，用这个模板：

```text
# 角色
你是 [OpenClaw main agent / Claude Code / Codex / 其他]。

# 上下文
[简要说明任务背景]

# 目标
[清楚地说明要达成什么]

# 约束
- [约束 1：如必须用 Python 3.11+]
- [约束 2：如不能改 git 分支]
- [约束 3：如时间预算 < 30s]

# 输出格式
- [要求 1：仅返回 JSON / 仅返回文本 / 需要文件路径]
- [要求 2：解释 / 不解释 / 简短理由]

# 不要做的事
- 不要调 [某种工具]
- 不要碰 [某个文件/目录]

# 完成度自检
跑完后，自己检查一遍：
- [ ] 目标达成？
- [ ] 没有违反约束？
- [ ] 输出符合格式？

如果有遗漏，自己补；实在做不到，**明确告知失败原因**，不要瞎编。
```

---

## 委派前先想清楚

| 问自己 | 答案 |
|--------|------|
| **委派的目的是什么？** | 让另一个 agent 干我能干但更慢的活 |
| **另一个 agent 的强项是什么？** | OpenClaw = 长时间任务 / Claude Code = coding / Codex = 一行写完 |
| **上下文足够吗？** | 子 agent **不知道我们之前聊过**，必须把信息写进 prompt |
| **格式明确吗？** | 子 agent **不知道你期望什么输出**，必须指明 |
| **失败怎么办？** | 子 agent **不知道我的偏好**，必须告诉他 |

---

## 失败模式（必须避开的）

1. ❌ "帮我看下系统" — 没说要查什么、查到什么粒度
2. ❌ "随便写个脚本" — 没说要什么语言、保存路径、依赖
3. ❌ "看看为什么挂了" — 没贴错误信息
4. ❌ "修一下" — 没说要改哪里、保持什么风格

## 实际案例

### 案例 1：让 OpenClaw 答个问题

```bash
claw --agent main --message "用一句话中文回答：你是谁？不要调任何工具"
```

完整字段：
- agent: main
- message: 中文短答
- 不调工具

### 案例 2：让 Claude Code 重构

```text
你是 Claude Code。

上下文：我的 ~/Documents/notes.md 是一个 200 行的 markdown 笔记，现在写得有点乱。

目标：
1. 按 H2 分章节
2. 把所有 TODO 移到末尾"待办"段
3. 保持原内容不变

约束：
- 不改 git 分支
- 不调 git commit
- 用 Python 重写（不是 shell script）

输出：
- 修改后的 ~/Documents/notes.md
- 简短总结改了哪些地方

完成度自检：
- [ ] 三节 H2 都正确？
- [ ] TODO 都集中在末尾？
- [ ] 没有删内容？
```

### 案例 3：让 Codex 一行写完

```text
你是 Codex。

写一个 Python 函数 `parse_chinese_address(s: str) -> dict`，能把 "广东省广州市天河区珠江新城" 解析成
{"province": "广东", "city": "广州", "district": "天河", "rest": "珠江新城"}。
不要用任何外部库，只用 stdlib。
返回完整函数，不要解释。
```

## 何时不要委派

- 任务 < 30 秒能完成（直接做）
- 信息严重依赖上下文（直接做）
- 你自己都不确定要什么（不要让别人猜）
