# 教程：self-reflect

> 适用：任何 LLM（ChatGPT / Claude / 本地 7B 模型 / Hermes 自身）

## 何时用

- ✅ 复杂技术决策（换框架吗？）
- ✅ 投资判断（A 股要不要买？）
- ✅ 法律 / 合规评估
- ✅ 任何"不能错"的关键问题
- ❌ 闲聊 / 简单查询（用极简版即可）
- ❌ 编码（直接写代码更好）

## 30 秒上手

```bash
# 1. 复制主模板（你机器上的位置）
cat ~/.local/share/prompts/universal-self-reflect.md
# 或直接看 https://github.com/gordonho/prompt-library/blob/main/prompts/general/self-reflect.md

# 2. 把 [在此填入你的问题] 替换成真实问题
# 3. 复制粘贴到任何 LLM
# 4. 看它严格按 5 段输出
```

## 实战：跟本地 7B 模型对话

### 准备工作
```bash
# 如果跑 Ollama
ollama run qwen:7b

# 复制主模板进对话
```

### 对话示例

**用户输入**：
```text
# 角色
你是一个严谨的分析助手。

# 任务
请回答以下问题：我开了 3 年的 Python SaaS 现在月收入 5 万元，要不要辞职全力做？

# 输出格式（严格遵守，禁止跳步）
【第 1 段 · 理解问题】
...（下面原文不变）...
```

**模型输出**（节选）：
```
【第 1 段 · 理解问题】
你的核心问题是判断是否应该从兼职模式转为全职创业。
关键约束：(1) 当前有稳定工作；(2) SaaS 月入 5 万；(3) 个人储蓄可支撑时间。

【第 2 段 · 拆解步骤】
1. 评估 SaaS 的增长趋势是否真实
2. 评估全职后是否能继续增长
3. 评估风险承受度（储蓄 / 家庭 / 心理）
4. 评估退出成本（辞职 ≠ 不能回头）

【第 3 段 · 逐步求解】
1. SaaS 月入 5 万的来源稳定性？需 12+ 月数据判断
2. 全职 vs 兼职的边际效益？时间翻倍，收入能翻倍？
3. 假设月支出 1.5 万，6 个月缓冲 → 至少 10 万可用储蓄
4. ...

【第 4 段 · 自我反思】
- 我假设了"边际效益 = 1"，实际可能 0.5
- 漏掉了健康保险 / 五险一金的隐性成本
- "6 个月缓冲"未考虑突发事件

【第 5 段 · 最终答案】
不建议立即辞职：先积累 12+ 月数据确认趋势 + 保留至少 12 个月缓冲 + 兼职逐步过渡到 80% 工时；满足后再评估全职。
```

## 进阶：高级版（多解投票 + 反思）

适用于**真正的关键决策**（投资 / 合规 / 医疗）：

```
3 个候选答案 + 自我反思 + 投票 + 最终裁定
Token 成本：2-3 倍普通对话
准确率：最高（53% → 87%）
```

## 何时升级 / 降级

| 场景 | 版本 |
|------|------|
| 闲聊、查资料 | 极简版（1 句话） |
| 普通技术问题 | 主模板 |
| 投资 / 合规 / 关键决策 | 高级版 |
| 写代码 / 调脚本 | 不需要这个模板（直接写） |

## 跟 Hermes 的关系

Hermes 默认就用主模板工作流处理你的请求。如果你想强制升级：

```
你："用高级版回答：XXX"
```

## 验证你的使用

跑完后问自己：
- [ ] 模型严格按 5 段输出了？
- [ ] 第 3 段没有跳步？
- [ ] 第 4 段真的找出了问题？
- [ ] 最终答案有依据？

## 失败模式

| 失败 | 修正 |
|------|------|
| 模型直接给答案不拆解 | 强调"**禁止跳步**" |
| 反思走过场（"看起来都对"）| 强调"**真实寻找问题**" |
| 信息不足但硬给结论 | 强调"**信息不足明确告知**" |
