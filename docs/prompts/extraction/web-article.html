🕸️ extraction / web-article

抓取微信文章 / 政府网站 / PDF / A 股数据。关键词监控。

⭐⭐ 进阶 🐍 Python 📰 微信公众号

📌 何时用

  • ✅ 抓微信公众号文章（mp.weixin.qq.com）
  • ✅ 抓政府 / 考试院 / 高校官网
  • ✅ PDF 表格抽取（pdftotext + 解析）
  • ✅ A 股实时数据 + 技术指标
  • ✅ 监控关键词 + 推送

🔑 公众号文章的关键技巧

微信公众号文章抓取有 3 个常见坑：

字段陷阱正确姿势
标题用 <title> 抓到的是 description用 <meta og:title>
公众号昵称JSON-escaped: nickname=\x22...\x22正则匹配 nickname=\\x22([^\\]+)\\x22
发布时间URL-encoded: %22publish_time%22%3A1784346712%7D正则匹配 %22publish_time%22%3A(\d{10})

🔑 政府网站的列表结构

典型结构（如广东考试院 eea.gd.gov.cn）：

<ul class="list">
  <li><a href="https://eea.gd.gov.cn/ptgk/content/post_XXX.html">
    <span class="line"></span>标题</a>
    <span class="time">2026-07-16</span>
  </li>
</ul>

注意 URL 是**完整**不是相对路径。
