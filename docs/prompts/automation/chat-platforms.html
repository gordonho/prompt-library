💼 企微（无表格）

企微 markdown 不支持表格。需要先转列表：

def table_to_list(table_md):
    """markdown 表格 → 企微兼容列表"""
    lines = table_md.split("\n")
    rows = [l for l in lines if l.startswith("|") and "---" not in l]
    headers = [h.strip() for h in rows[0].split("|") if h.strip()]
    items = []
    for r in rows[1:]:
        cells = [c.strip() for c in r.split("|") if c.strip()]
        item = "".join(f"**{h}**: {c}\n" for h, c in zip(headers, cells))
        items.append(item)
    return "\n---\n".join(items)

⚠️ 安全提示

  • Webhook URL 不要提交到 git — 用 .env
  • 测试 webhook 不要发到生产群
  • 大批量推送要分批，每批间隔 5-10s
  • 消息超限要截断或分块（飞书 30KB / 企微 4KB）
