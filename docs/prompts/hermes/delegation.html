🤝 hermes / delegation

跨 agent 委派任务模板。OpenClaw / Claude Code / Codex 都适用。

⭐⭐ 进阶 ⏱️ 30 秒上手 🤖 Hermes + 子 agents

📌 何时用

  • ✅ 需要另一个 agent 干"脏活"（长跑 cron、大文件扫描、复杂代码生成）
  • ✅ 保持主对话简洁，让子 agent 在后台跑
  • ✅ 并行多个子任务
  • ❌ 任务 < 30 秒能搞定（直接做）
  • ❌ 信息严重依赖上下文（直接做）

🚀 主模板

# 角色
你是 [OpenClaw main agent / Claude Code / Codex / 其他]。

# 上下文
[简要说明任务背景]

# 目标
[清楚地说明要达成什么]

# 约束
- [约束 1：如必须用 Python 3.11+]
- [约束 2：如不能改 git 分支]
- [约束 3：如时间预算 < 30s]

# 输出格式
- [要求 1：仅返回 JSON / 仅返回文本 / 需要文件路径]
- [要求 2：解释 / 不解释 / 简短理由]

# 不要做的事
- 不要调 [某种工具]
- 不要碰 [某个文件/目录]

# 完成度自检
跑完后，自己检查一遍：
- [ ] 目标达成？
- [ ] 没有违反约束？
- [ ] 输出符合格式？

如果有遗漏，自己补；实在做不到，**明确告知失败原因**，不要瞎编。

💡 5 条设计原则

  1. 明确角色 — "你是 X agent"
  2. 明确上下文 — 子 agent 不知道之前聊过
  3. 明确目标 — 含糊会失败
  4. 明确约束 — "不要碰 git / 不要超时"
  5. 明确输出格式 — "返回 JSON / 简短 / 完整"
