📜 设计原则

  1. 实战验证 · 每个模板都来自真实 Hermes Agent 使用场景
  2. 可复用 · 不依赖特定工具，复制即可用
  3. 结构化 · 都有 输入 / 输出 / 限制 三个明确段
  4. 反例丰富 · 标出"不要做什么"，避免踩坑
