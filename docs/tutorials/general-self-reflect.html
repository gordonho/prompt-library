📖 教程：self-reflect

30 秒上手 + 实战案例 + 流程图

30 秒上手

  1. 复制 主模板
  2. 把 [在此填入你的问题] 替换成你的真实问题
  3. 粘贴到任何 LLM（ChatGPT / Claude / 本地 7B / Hermes）
  4. 让模型严格按 5 段输出

三版选择

场景版本
闲聊、查资料极简版（1 句话）
普通技术问题主模板
投资 / 合规 / 关键决策高级版
写代码 / 调脚本不需要这个模板

验证你的使用

  • 模型严格按 5 段输出了？
  • 第 3 段没有跳步？
  • 第 4 段真的找出了问题？
  • 最终答案有依据？
