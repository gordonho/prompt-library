📖 教程：watchdog

常驻守护进程设计 · 30 秒上手 + 实战 + 流程图

何时用

  • ✅ 跑了关键服务（Hermes 网关 / 数据库 / 队列）
  • ✅ launchd KeepAlive 不够（不能救 OOM / JS hang）
  • ✅ 想要"静默优先"（失败才推用户）
  • ❌ 普通 cron（用 cron 模板）
  • ❌ 一次性任务

30 秒上手

  1. 写 watchdog 脚本（参考 prompts/monitoring/watchdog.md）
  2. 写 launchd plist（参考 watchdog 模板）
  3. launchctl load -w ~/Library/LaunchAgents/com.example.plist
  4. tail -f ~/.local/log/mywatch.log 看日志

状态机

IDLE ─probe→ HEALTHY ─probe→ HEALTHY
                │
                ↓ probe fail
                HEALTHY → DEGRADED (fails=1)
                              │
                              ↓ probe fail
                              DEGRADED (fails=2)
                              ...
                              DEGRADED (fails=5)
                                              │
                                              ↓
                                              TRIGGERED (cooldown 5min)
                                                              │
                                                              ↓ cooldown end
                                                              HEALTHY

实战：Hermes ↔ OpenClaw 互救

INTERVAL = 60        # 秒
THRESHOLD = 5        # 累计失败
COOLDOWN = 300       # 重启后冷却

实际跑过的场景（已救活 Hermes 网关 1 次）：

13:07:46  Hermes failed probe (5/5)
13:07:46  Hermes triggering force restart
13:07:47  Hermes kickstart dispatched

关键陷阱

陷阱解决
launchd 进程 PATH 缺 venv用绝对路径
探针正常时也推送完全静默
探针失败立即重启累计阈值 + 冷却
多个 watchdog 互相监视单 watchdog + launchd
用 cron 跑 watchdogwatchdog 是常驻进程
