📖 教程：delegation

跨 agent 委派任务给 OpenClaw / Claude Code / Codex

何时用

  • ✅ 需要另一个 agent 干"脏活"
  • ✅ 保持主对话简洁，让子 agent 在后台跑
  • ✅ 并行多个子任务
  • ❌ 任务 < 30 秒能搞定（直接做）
  • ❌ 信息严重依赖上下文（直接做）

30 秒上手

模式 1 — Hermes → OpenClaw：

~/.local/bin/claw --agent main --message "你的具体任务"

模式 2 — Hermes → Claude Code / Codex：

delegate_task(
  goal="写一个 Python 脚本...",
  context="我的项目是...，要遵守...",
  model="sonnet"  # 可选
)

设计原则

  1. 明确角色 — "你是 X agent"
  2. 明确上下文 — 子 agent 不知道之前聊过
  3. 明确目标 — 含糊会失败
  4. 明确约束 — "不要碰 git / 不要超时"
  5. 明确输出格式 — "返回 JSON / 简短 / 完整"
  6. 明确完成度 — "完成后自检：a, b, c"
