📖 教程：web-article

数据提取 · 30 秒上手 + 实战 + 流程图

何时用

  • ✅ 抓微信公众号文章（mp.weixin.qq.com）
  • ✅ 抓政府 / 考试院 / 高校官网
  • ✅ PDF 表格抽取
  • ✅ A 股实时数据 + 技术指标
  • ✅ 监控关键词 + 推送

30 秒上手

微信公众号文章：

~/.local/bin/wx_article.py "https://mp.weixin.qq.com/s/XXX" --keyword "中山大学"

政府网站监控：

~/.local/bin/gk_monitor.py

A 股实时：

~/.local/bin/stock_push.py

流程图

   URL / API / PDF
        │
        ▼
   ┌──────────┐
   │  fetch()  │  HTTP/curl/requests
   └────┬─────┘
        │ raw HTML/JSON/PDF text
        ▼
   ┌──────────┐
   │  parse()  │  正则 / JSON / pdfplumber
   └────┬─────┘
        │ dict {title, body, date, ...}
        ▼
   ┌──────────┐
   │  render() │  markdown 模板
   └────┬─────┘
        │
        ▼
   ┌──────────┐
   │  push    │  WeChat / QQ bot / Slack
   └──────────┘

关键陷阱

陷阱解决
公众号标题在 og:title 不在 title用 og:title 优先
公众号昵称是 JSON-escaped (\x22)正则匹配 \x22
公众号发布时间 URL-encoded正则匹配 %22publish_time%22%3A(\d+)
政府网站 URL 是完整不是相对正则匹配 https?:// 可选
HTML 标签混入文本re.sub(r'<[^>]+>', '\n')
