📖 教程：chat-platforms

飞书 / 企微 / Slack 推送 · 30 秒上手 + 平台速查

何时用

  • ✅ 把脚本输出推送到多个平台
  • ✅ 企业团队机器人
  • ✅ CI/CD 通知
  • ❌ 给个人微信推（用 QQ bot 或 iLink）
  • ❌ 不需要通知（用 cron local）

30 秒上手

飞书：

curl -X POST "$FEISHU_WEBHOOK" \
  -H "Content-Type: application/json" \
  -d "$(jq -n --arg c "$MSG" '{
    msg_type: "interactive",
    card: {
      header: {title: {tag: "plain_text", content: "标题"}, template: "blue"},
      elements: [{tag: "div", text: {tag: "lark_md", content: $c}}]
    }
  }')"

企微：

curl -X POST "$WECOM_WEBHOOK" \
  -H "Content-Type: application/json" \
  -d "$(jq -n --arg c "$MSG" '{msgtype:"markdown",markdown:{content:$c}}')"

平台速查

平台Markdown限制
飞书lark_md（最丰富）30KB / 条
企微有限（不支持表格）4KB / 条
Slackmrkdwn（*bold*）40KB / 条
TelegramMarkdownV2（需转义）4096 char

Slack mrkdwn ≠ 标准 markdown

普通 markdownSlack
**bold***bold*
*italic*_italic_
~~strike~~~strike~

安全提示

  • Webhook URL 不要提交到 git — 用 .env
  • 测试 webhook 不要发到生产群
  • 大批量推送要分批，每批间隔 5-10s
  • 消息超限要截断或分块（飞书 30KB / 企微 4KB）
